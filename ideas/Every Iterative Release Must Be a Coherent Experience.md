Customer-centered planning means each iterative release delivers a complete, coherent experience — not a collection of features that only coheres at some distant finish line. Inspired by Henrik Kniberg's MVP diagram, this principle holds that partial delivery should still feel whole to the user at each stage, even if it is limited in scope. Design must be involved in shaping what each increment includes, not just how it looks.
